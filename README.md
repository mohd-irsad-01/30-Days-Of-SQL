📌 About This Repository

This repository contains my SQL practice journey completed over 30 days using Oracle SQL.

During this challenge, I practiced 100 SQL queries covering fundamental to advanced SQL concepts using Oracle's "EMP" and "DEPT" tables.

The main goal of this challenge was to strengthen my database fundamentals, improve query-writing skills, and develop problem-solving abilities.
